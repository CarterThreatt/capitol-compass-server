CAPITOL COMPASS

Capitol Compass API

The data behind the Capitol Compass guide to Washington, D.C. Every request below is a GET request that sends back JSON or a picture.

See it on the website

Available requests

GET /api/monuments

Every monument and memorial on the Mall as a list: name, photo, category, hours, how long to stay, and ticket links for the ones that need them.

All Monuments
GET /images/<img_name>

The photo for each monument. Use the img_name that comes back from the monuments request, like lincoln-memorial.jpg.
